# Job Application Assistant

A lightweight, privacy-first web tool built with pure HTML, CSS, and JavaScript to streamline your job search. Everything runs directly in your browser—no data is sent to external servers.

## Features
1. **Resume & Job Description Analyzer:** Calculates a keyword alignment score, highlights matched skills, identifies missing ATS keywords, and gives actionable resume tips.
2. **Custom Cover Letter Generator:** Generates editable cover letters tailored to the job posting in three tones (*Professional*, *Enthusiastic*, and *Concise*) with one-click copy and PDF print support.
3. **Interview Prep Questionnaire:** Creates role-specific technical, behavioral, and gap-focused interview questions complete with STAR-method answering tips.
4. **Privacy & Convenience:** Includes browser `localStorage` auto-save and a built-in Dark Mode toggle.

## How to Use
- Open the live GitHub Pages link (or double-click `index.html` locally).
- Paste your resume and target job description.
- Click **Analyze & Generate Materials** to view your match score, cover letter, and interview questions.
